# 拷贝漫画下载器

基于 Rust + reqwest + tokio 的命令行漫画下载器（CLI 版），支持拷贝漫画、zerobyw 搬运网两个漫画源，支持搜索下载、增量检查更新、完结标记与协作式取消。

## 功能

### 1. 搜索并下载漫画
- 按关键词搜索站点漫画，展示前 12 条结果
- 选定漫画后拉取完整章节大纲，按起始/结束话数下载指定区间
- 下载前将章节元数据落盘为 JSON，方便后续检查更新时复用

### 2. 指定漫画检查更新
- 从本地 `download/` 目录列出已下载漫画（含已下载话数、完结状态）
- 选定一部后只检查该漫画的线上章节，发现新章节则直接全部下载
- 适合「我只追这一部」的场景，避免全量扫描等待

### 3. 检查全部更新
- 扫描本地所有已下载漫画，逐部对比线上章节
- 汇总有更新的漫画列表，选择后一次性下载该漫画的全部新章节
- 已标记完结的漫画会被跳过，不再请求线上接口

### 4. 标记漫画是否完结
- 在 `<漫画名>.json` 中维护 `completed` 字段，默认 `false`（未完结）
- 可在菜单中切换完结/未完结状态
- 完结后检查更新时直接跳过；保存章节详情时会保留已有完结标记，不会被覆盖

### 5. 取消与退出
- 任意阶段按一次 `Ctrl+C`：返回主菜单
- 再按一次 `Ctrl+C`：直接退出程序
- 下载过程中可取消当前任务，半截文件会被清理

## 漫画源

启动时选择漫画源：`1:拷贝漫画(默认)  2:zerobyw搬运网`，之后所有搜索/下载/更新检查都走选定的源。

### zerobyw 搬运网
- 纯 HTML 站点适配器，未登录时每部漫画只有前几话未上锁
- 选中该源后会出现登录引导，输入 zerobyw 账号密码即可登录；登录会话保存在 `download/.zerobyw_cookies.json`，下次启动自动恢复，无需重复登录
- 锁定章节分两类并分别提示：`需登录`章节登录后解锁；`VIP` 章节是站点权限限制，登录也无法阅读。两类都只提示并跳过
- 登录可随时跳过（跳过 / Ctrl+C / 输入错误密码后放弃都不影响主流程），未登录仅能下载未上锁章节

## 菜单

```
1:搜索  2:指定漫画检查更新  3:检查全部更新  4:标记完结  5:退出
```

## 实现原理

### 网络与解密
- 客户端使用固定 `Referer` 与浏览器 UA，基于 rustls（`reqwest` + `stream`）
- 搜索接口返回明文 JSON，直接反序列化
- 章节大纲、图片直链等接口返回 AES-CBC 密文：
  1. 从页面 HTML 中用正则提取密钥与 token
  2. 调用详情接口拿到 `results` 密文字段
  3. 对密文解密后，再解析为 JSON
- 关键请求之间插入 `REQUEST_DELAY`（1s）与页级限速，降低触发站点限流的概率

### 下载
- 边拉直链边下载：逐话串行拉取直链（话间歇 1s 防限流），直链一到手即转后台下载，与下一话的直链拉取重叠，不必等全部直链拉完才开始
- 每章创建 `download/{漫画名}/{章节名}/` 目录
- 页面级并发由 `Semaphore(64)` 限制，`indicatif` 进度条展示进度
- 单页流式写入 `{页码}.webp`，失败自动重试；超时或取消时删除半截文件
- 取消通过 `Arc<AtomicBool>` 协作检查：章节派发、页派发、任务启动、重试循环、写流各处轮询

### 更新检查
- 本地状态完全由文件系统推导，无独立数据库：
  - 一级目录名 = 漫画名
  - 二级目录名 = 已下载章节名
  - `<漫画名>.json` 缓存 `path_word` 与 `completed`，以及完整线上章节快照
- 检查流程：
  1. 读本地 JSON 取 `path_word`；跨源检查（漫画记录于其他源）或没有缓存时，按漫画名在当前源联网精确反查——任何源都可以检查任意本地漫画的更新
  2. 拉取线上章节大纲并落盘（顺带刷新 `path_word` 缓存）
  3. 用 `HashSet` 对比本地章节目录与线上章节，差集即为新章节
  4. 已完结（`completed == true`）直接跳过
- 全量检查按漫画顺序进行，每部之间 sleep，避免并发打爆限流

### 完结标记
- `set_manga_completed` 读改写 `<漫画名>.json`；文件不存在时会创建最小 JSON
- `save_chapter_details` 写入前若发现磁盘上已有 `completed`，会保留该值，避免更新章节时冲掉用户标记

### 目录结构示例

```
download/
└── 漫画名/
    ├── 漫画名.json          # path_word / completed / 章节快照
    └── 第1话/
        ├── 1.webp
        ├── 2.webp
        └── ...
```

## 构建

在根目录下运行：

```
cargo build --release
```

生成的 exe 位于 `target/release/` 下。
